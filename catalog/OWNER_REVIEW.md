# Утверждение каталога владельцем

Каталог утверждён владельцем 21 октября 2026 года. Он содержит 225 уникальных вариантов: 104 нижних, 74 верхних, 22 антресоли и 25 дополнительных элементов. Для каждого варианта рассчитана отдельная стоимость крепежа. Компоненты с пометкой `Покупают сами` в стоимость не входят.

## Утверждённые решения

### 1. Три сдвинутые последовательности

Подтверждены следующие исправления:

- Нижняя обычная полка: `НГП 601` — 600 мм и два фасада; затем `НГП 650`–`НГП 900`; отдельного варианта 950 мм нет.
- Верхняя распашная полка: `СДП 601` — 600 мм и два фасада; затем `СДП 650`–`СДП 900`.
- Верхняя съёмная полка: `СДСП 601` — 600 мм и два фасада; затем `СДСП 650`–`СДСП 800`.

Исходные строки и исправления сохранены в отчёте.

### 2. Восстановленный Aventos 450

Для `СДСУА 450` утверждено: корпус 0,71 м², фасад 0,31 м², ХДФ 0,29 м². Набор Aventos покупает клиент, поэтому он не включён в цену.

### 3. Подрезка по ширине

Подрезка разрешена для всех модулей, кроме духовки, вытяжки, посудомойки, бутылочницы, пеналов, сушек и дополнительных элементов. Максимальное уменьшение — 50 мм с шагом 1 мм, не более двух подрезаемых модулей в ряду.

### 4. Публичные названия семей

Утверждены названия:

- Нижние: модуль под мойку, модуль для посудомоечной машины, модуль с полкой, модуль со съёмной полкой, угловой модуль под мойку, угловой модуль со съёмной полкой, пенал для холодильника, модуль с двумя ящиками, модуль с тремя ящиками, модуль со скрытой парой ящиков, модуль для духовки, бутылочница.
- Верхние: модуль с Aventos HF, модуль с подъёмником KLOK, модуль с распашным фасадом, модуль со съёмной полкой, модуль для сушки, модуль для сушки с Aventos HF, модуль для вытяжки, угловой верхний модуль.
- Остальные: антресоль, корона, глубокая корона, цоколь, фальш-панель.

## Согласование с бухгалтером

### Формулировка НДС

Владелец и бухгалтер утвердили правило 21 октября 2026 года: рассчитанная цена без НДС умножается на 1,10, итог округляется до 10 рублей, после чего НДС показывается как `22/122` от итоговой суммы.

## Контрольная кухня

Подготовлена прямая кухня длиной 2700 мм во всех трёх рядах, с фасадами и упаковкой. По стартовым ставкам расчёт без НДС составляет 50 257,75 руб., итоговая цена после коэффициента и округления — 55 280 руб., в том числе НДС — 9 968,52 руб. Это тестовый пример, заявка никуда не отправляется.

## Дополнительные элементы

- Фальш-панель добавляется клиентом вручную и занимает в ряду свою физическую толщину 16 мм.
- Цоколь считается по фронтальной длине нижних модулей и пеналов.
- Корона считается по фронтальной длине антресоли, а при её отсутствии — верхних модулей, плюс верх пеналов.
- Фальш-панель входит в длину цоколя или короны только при продолжении соответствующей фронтальной линии; боковые возвраты не считаются.
- Цоколь и корона продаются целыми элементами по 2700 мм с округлением количества вверх, без оптимизации остатков.

Контроль аксессуаров: 5400 мм напольного фронта и фальш-панель 16 мм дают 5416 мм и три цоколя; 2700 мм антресоли и верх пенала 600 мм дают 3300 мм и две короны.
